# Changelog

Все заметные изменения проекта SecureVault будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [1.1.2] - 2025-01-XX

### Исправлено
- Устранены Tcl-ошибки (`invalid command name`) при закрытии окна входа
- Исправлена критическая ошибка: `login.destroy()` вместо `app.destroy()` в `main.py`
- Добавлена задержка перед `quit()` для очистки Tcl-очереди

### Безопасность
- Добавлена очистка мастер-пароля из памяти при выходе из приложения
- Добавлен метод `VaultService.clear_password()`

### Добавлено
- Файл `CHANGELOG.md` для отслеживания изменений

## [1.1.1] - 2025-01-XX

### Исправлено
- Устранено зависание процесса в Windows после закрытия приложения
- Добавлен `sys.exit(0)` для принудительного завершения процесса
- Отмена всех таймеров и отвязка обработчиков при закрытии

## [1.1.0] - 2025-01-XX

### Добавлено
- Счётчик записей по категориям в фильтре (например: "работа (5)")
- Методы `get_category_counts()` и `get_categories_with_counts()`

### Исправлено
- Опечатки в именах переменных и docstrings

## [1.0.0] - 2025-01-XX

### Добавлено
- Первый стабильный релиз
- Шифрование AES-256-GCM через Fernet с Argon2id KDF
- Автоблокировка при неактивности (5 минут)
- Автосокрытие пароля (10 секунд)
- Безопасный буфер обмена с автоочисткой
- Аудит паролей (слабые и повторяющиеся)
- CRUD операции с записями
- Поиск и фильтрация по категориям
- Генератор паролей
- Горячие клавиши (Ctrl+N, F, L, G, E, I, Escape)
- Защита от брутфорса (экспоненциальная задержка)
- Экспорт/импорт CSV и JSON
- Смена мастер-пароля
- Версия приложения в заголовке и статус-баре
